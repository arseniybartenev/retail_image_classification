## Описание проекта  
Данный проект выполнен в рамках курса по глубокому обучению и посвящён разработке моделей компьютерного зрения для ритейла. Решаются две прикладные задачи:  
1. **Классификация одежды** для агрегатора магазинов – модель должна определять категорию товара по чёрно-белому фото (футболка, брюки, платье и т.д.).  
2. **Классификация фруктов и овощей** для системы весов самообслуживания в супермаркете – модель по цветному изображению определяет вид продукта.  

**Цель:** построить и обучить нейросетевые классификаторы, достигающие высокой точности на тестовых выборках при ограниченном времени обучения (для фруктов – не более 1 часа для кастомной CNN и 30 минут для ResNet).

## Данные  
В проекте используются два набора данных:

- **Fashion-MNIST** – 70 000 чёрно-белых изображений одежды размером 28×28 пикселей (60 000 обучающих, 10 000 тестовых). 10 классов: футболка, брюки, свитер, платье, пальто, сандалии, рубашка, кроссовки, сумка, ботинки.  
  Файлы:  
  - `train_features.npy`, `train_target.npy`  
  - `test_features.npy`, `test_target.npy`  

- **Fruits** – набор цветных фотографий фруктов и овощей (12 классов, например яблоки, бананы, апельсины, помидоры и т.д.). Изображения хранятся в папке `fruits_small`, организованной по классам. Полная версия датасета используется на GPU-сервере.

## Этапы работы  

### 1. Классификация одежды: полносвязная сеть  
**Файл:** `fashion_mnist_fcnn.py`  
- Загрузка данных из `.npy` файлов.  
- Нормализация пикселей (деление на 255) и преобразование изображений в плоский вектор (28×28 = 784).  
- Простая полносвязная сеть: 3 скрытых слоя (256, 128, 64 нейрона, ReLU), выходной слой (10 нейронов, softmax).  
- Оптимизатор: SGD, функция потерь: sparse_categorical_crossentropy.  
- Обучение 5 эпох, batch_size=32.  

**Результат:**  
- Train accuracy: **86.48%**  
- Test accuracy: **85.37%** (требование ≥85% выполнено)

### 2. Классификация одежды: свёрточная сеть (Adam)  
**Файл:** `fashion_mnist_cnn.py`  
- Данные загружаются и нормализуются, но сохраняют исходную форму (28,28,1).  
- Архитектура, вдохновлённая LeNet-5:  
  - Conv2D(6, 5×5, tanh) + AvgPool(2×2)  
  - Conv2D(16, 5×5, tanh) + AvgPool(2×2)  
  - Flatten → Dense(120, tanh) → Dense(84, tanh) → Dense(10, softmax)  
- Оптимизатор: Adam, learning_rate по умолчанию.  
- Обучение 5 эпох.  

**Результат:**  
- Train accuracy: **89.50%**  
- Test accuracy: **87.96%** (требование ≥87% выполнено)

### 3. Классификация фруктов: кастомная свёрточная сеть  
**Файл:** `fruits_cnn.py`  
- Использован `ImageDataGenerator` для аугментации:  
  - Поворот до 10°, сдвиг по ширине/высоте (0.1), горизонтальное отражение, масштабирование 1/255.  
- Изображения приводятся к размеру 150×150.  
- Архитектура:  
  - Conv2D(32, 5×5, ReLU) + AvgPool(2×2)  
  - Flatten  
  - Dense(12, softmax)  
- Оптимизатор: Adam (lr=0.001).  
- Обучение 10 эпох, batch_size=16.  

**Результат:**  
- Train accuracy: **92.56%**  
- Test accuracy: **92.35%** (требование ≥90% выполнено за время <1 часа)

### 4. Классификация фруктов: ResNet50  
**Файл:** `fruits_resnet.py`  
- Предобученная на ImageNet модель ResNet50 (без верхушки) загружается с весами.  
- Добавлены слои: GlobalAveragePooling2D → Dense(12, softmax).  
- Тонкая настройка с очень низкой скоростью обучения (Adam, lr=0.00001).  
- Аугментация расширена: добавлен zoom_range=0.1.  
- Обучение 6 эпох.  

**Результат:**  
- Train accuracy: **99.84%**  
- Test accuracy: **99.95%** (требование ≥99% выполнено за <30 минут)

## Используемые технологии  
- **Python** – основной язык программирования.  
- **TensorFlow/Keras** – построение и обучение нейросетей.  
- **NumPy** – работа с массивами данных.  
- **ImageDataGenerator** – аугментация изображений и загрузка данных из каталогов.  
- **ResNet50** – предобученная архитектура для трансферного обучения.  
- **Adam, SGD** – оптимизаторы.  

## Результаты  

| Модель                      | Датасет        | Test Accuracy |
|-----------------------------|----------------|---------------|
| Полносвязная сеть (SGD)     | Fashion-MNIST  | 85.37%        |
| Свёрточная сеть (Adam)      | Fashion-MNIST  | 87.96%        |
| Кастомная CNN               | Fruits         | 92.35%        |
| ResNet50 (fine-tune)        | Fruits         | 99.95%        |

Все модели удовлетворяют поставленным требованиям по точности и времени обучения.

## Выводы  
- Для простого датасета одежды даже полносвязная сеть даёт приемлемый результат, но свёрточная архитектура улучшает качество.  
- На более сложном наборе фруктов кастомная CNN с аугментацией достигает 92%, что уже пригодно для использования.  
- Использование предобученной ResNet50 с тонкой настройкой позволяет достичь практически идеальной точности (99.95%) за короткое время, что идеально для промышленного внедрения в систему весов самообслуживания.  

Разработанные модели могут быть интегрированы в приложения ритейла для автоматического распознавания товаров, ускорения обслуживания и снижения ошибок.

## Запуск проекта  

1. Клонируйте репозиторий:  
   ```bash
   git clone https://github.com/your-username/image-classification-retail.git
   cd image-classification-retail
   ```

2. Установите зависимости:  
   ```bash
   pip install -r requirements.txt
   ```

3. Подготовьте данные:  
   - Поместите файлы `.npy` для Fashion-MNIST в директорию проекта или укажите путь в скриптах.  
   - Распакуйте датасет `fruits_small` в папку `datasets/fruits/` (структура: `fruits_small/class_name/*.jpg`).  

4. Запустите любой из скриптов:  
   ```bash
   python fashion_mnist_fcnn.py
   python fashion_mnist_cnn.py
   python fruits_cnn.py
   python fruits_resnet.py
   ```

   > **Примечание:** для обучения на GPU сервере пути к данным и весам ResNet50 могут отличаться (см. комментарии в коде).
