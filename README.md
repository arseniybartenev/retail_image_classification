## Описание проекта  
Проект посвящён разработке систем компьютерного зрения для ритейла с использованием методов глубокого обучения. Решаются две прикладные задачи:  
- **Классификация одежды** для агрегатора магазинов – модель определяет категорию товара по чёрно-белому изображению (футболка, брюки, платье и т.д.).  
- **Классификация фруктов и овощей** для автоматизированных весов в супермаркете – модель по цветной фотографии определяет вид продукта.  

Все модели обучаются с соблюдением требований по точности и времени выполнения: для фруктов кастомная свёрточная сеть должна обучаться не более 1 часа, а ResNet50 – не более 30 минут.

## Данные  
- **Fashion-MNIST**: 70 000 чёрно-белых изображений одежды размером 28×28 пикселей, разделённых на 10 классов.  
- **Fruits**: цветные фотографии фруктов и овощей (12 классов), полная версия датасета используется на GPU-сервере.  

## Задачи и требования  
1. **Fashion-MNIST (полносвязная сеть)** – точность на тестовой выборке ≥85%.  
2. **Fashion-MNIST (свёрточная сеть + Adam)** – точность ≥87%.  
3. **Fruits (кастомная CNN)** – точность ≥90% при времени обучения ≤1 час.  
4. **Fruits (ResNet50)** – точность ≥99% при времени обучения ≤30 минут.

## Реализованные модели  
Проект включает четыре скрипта в папке `src/` и один Jupyter Notebook в папке `notebooks/`:  
- `src/fashion_mnist_fcnn.py` – полносвязная сеть (3 скрытых слоя: 256, 128, 64 нейрона, ReLU; оптимизатор SGD).  
- `src/fashion_mnist_cnn.py` – свёрточная сеть, вдохновлённая LeNet-5 (блоки Conv+Pool, затем полносвязные слои; оптимизатор Adam).  
- `src/fruits_cnn.py` – кастомная CNN с аугментацией данных (повороты, сдвиги, отражения; Adam).  
- `src/fruits_resnet.py` – трансферное обучение на базе ResNet50 (предобучена на ImageNet) с тонкой настройкой (очень низкая скорость обучения).  
- `notebooks/retail_image_classification.ipynb` – Jupyter Notebook, объединяющий все четыре подхода с подробными пояснениями, выводом процесса обучения и заключениями.

## Результаты  

| Модель                     | Датасет        | Тестовая точность |
|----------------------------|----------------|-------------------|
| Полносвязная сеть (SGD)    | Fashion-MNIST  | 85.4%             |
| Свёрточная сеть (Adam)     | Fashion-MNIST  | 88.0%             |
| Кастомная CNN              | Fruits         | 92.4%             |
| Тонкая настройка ResNet50  | Fruits         | 99.95%            |

Все модели удовлетворяют поставленным требованиям.

## Получение данных  
Так как файлы с данными имеют большой объём, они не включены в репозиторий. Для работы с проектом используйте следующие инструкции:

### Fashion-MNIST  
Данные загружаются автоматически через `tensorflow.keras.datasets.fashion_mnist.load_data()` при первом запуске скриптов. Никаких дополнительных действий не требуется.

### Fruits dataset  
**Вариант 1: Полная версия (рекомендуется для обучения)**  
Скачайте датасет с [Kaggle (Fruits 360)](https://www.kaggle.com/datasets/moltean/fruits)   
После скачивания распакуйте архив в папку `datasets/fruits_small/` так, чтобы структура соответствовала:  
```
datasets/fruits_small/
├── Apple/
│   ├── 1.jpg
│   ├── 2.jpg
│   └── ...
├── Banana/
│   ├── 1.jpg
│   └── ...
└── ... (остальные классы)
```

**Вариант 2: Тестовая подвыборка (для проверки кода)**  
Если вы хотите только опробовать код без загрузки полного датасета, можно создать собственную маленькую выборку, скопировав несколько изображений каждого класса в указанную структуру папок. Либо воспользуйтесь скриптом `download_sample_data.py` (если он будет добавлен).

## Используемые технологии  
- Python 3.9  
- TensorFlow 2.16.2 / Keras 3.13.2 – построение и обучение нейросетей  
- NumPy 2.4.2 – работа с данными  
- ImageDataGenerator – аугментация изображений и загрузка из каталогов  
- ResNet50 – предобученная архитектура для трансферного обучения  
- Jupyter Notebook – интерактивная среда разработки и документирования  

## Установка и запуск  
1. Клонируйте репозиторий:  
   ```bash
   git clone https://github.com/your-username/retail-image-classification.git
   cd retail-image-classification
   ```  
2. Установите зависимости:  
   ```bash
   pip install -r requirements.txt
   ```  
3. Подготовьте данные (см. раздел [Получение данных](#получение-данных)).  
4. Запустите любой скрипт из папки `src/` или откройте ноутбук:  
   ```bash
   python src/fashion_mnist_fcnn.py
   python src/fashion_mnist_cnn.py
   python src/fruits_cnn.py
   python src/fruits_resnet.py
   jupyter notebook notebooks/retail_image_classification.ipynb
   ```  
   > **Примечание:** при работе на GPU-сервере пути к данным и весам ResNet50 могут отличаться.
